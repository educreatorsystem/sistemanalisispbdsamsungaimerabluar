# Sistem Analisis PBD — SEKOLAH AGAMA MENENGAH SUNGAI MERAB LUAR

Versi sistem asal tanpa PWA. Hanya konfigurasi Sheet ID, URL Apps Script, tiga URL CSV, nama sekolah dan lencana dikemas kini. Fungsi asal tidak diubah.

## GitHub Pages

Muat naik fail `index.html` di root repository dan aktifkan GitHub Pages menggunakan `main` dan `/(root)`.

Lencana menggunakan pautan imej luar yang diberikan. Internet diperlukan untuk memaparkan lencana dan memuatkan pustaka CDN/data.

Google Sheets serta Apps Script perlu diterbitkan dan dibenarkan akses yang sesuai supaya fungsi sistem boleh beroperasi.
